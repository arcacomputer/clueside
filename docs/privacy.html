Summary

This Chrome extension analyzes images entirely on your device. Image bytes are not uploaded to any server for inference, storage, or analytics.

What stays on your device

  • Webpage images fetched so pixels can be decoded locally
  • Files you drop into the toolbar popup
  • Model inference (WebGPU or WASM in an offscreen document)
  • Metadata parsing (C2PA, EXIF, embedded text)
  • Settings (threshold, enable, auto-scan) in chrome.storage.sync

What may use the network

  • Packaged models: both model weights (CommunityForensics ONNX and DINOv2-small ONNX with its probe head) ship inside the extension package. The weights are downloaded from Hugging Face at build/packaging time (npm run fetch-model), never by the installed extension. Models and inference assets are never fetched at runtime.
  • Update check: at most once a day the background worker asks the GitHub releases API for the latest version string so the popup can show an update banner. No image data or browsing data is sent; offline it fails silently.
  • Ordinary page loads still use the site's own network traffic. This extension does not add cloud inference calls and does not send image pixels to a backend.

Permissions

PermissionWhy
host_permissions / all_urls Fetch page image URLs so pixels can be decoded without canvas taint. Local analysis only.
offscreen Run ONNX inference in a document with canvas, WebGPU, or WASM.
storage Save your threshold and toggles.
unlimitedStorage Hold the on-device ~83MB ONNX weights. Not used to upload images.
activeTab Let the popup talk to the current tab when you drop a file or change settings.

Data we do not collect

  • No analytics
  • No image uploads
  • No account system
  • No external inference APIs

Children

This extension does not knowingly collect personal information from anyone, including children.
